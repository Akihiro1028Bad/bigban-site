# GEO 掲載チェック

## 考え方

AI アシスタントは「近くでピクルボールできるところは?」と聞かれると、自分で Google 検索をかけ、**第三者のまとめ記事・ランキング・施設一覧**を引用して答えることが多い。検索語は「おすすめ + 用件 + 地名 + 年」のような形になる。

したがって AI 検索対策の中心は次の2つ:

1. その検索語で上位にいるまとめ記事に**載せてもらう**(第三者の評価が引用される)
2. 自サイトの該当ページがその検索語で上位にいる

自サイトで自社を「おすすめ1位」にするランキング記事は作らない(第三者の評価ではないので引用されにくく、信頼も落とす)。

## やらないこと

- **被リンクの購入・相互リンクを条件にした掲載依頼**はしない(Google のスパムポリシー違反)。依頼は無償の情報提供として行う。
- 依頼メール・フォーム送信・会員登録・ログインを AI が行わない。**文面の下書きまで**作り、送るのはオーナー。
- 判定期間中の記事(Notion「記事ネタ案」や `docs/reviews/` に判定日がある記事)の title・excerpt を、この調査を理由に変えない。変えたい場合は判定日以降の改稿案として出す。

## 手順

### 1. 検索語を決める

前回の台帳(下記「記録先」)があればその検索語を引き継ぎ、増減だけ決める。初回・見直し時の基本セット:

- `ピクルボール おすすめ <市>` / `<県>` / `東京近郊`(年号あり・なしの両方)
- `ピクルボール コート <市>` / `屋内 ピクルボール <県>` / `ピクルボール できる場所 <県>`
- `HYROX 練習 ジム <県> おすすめ` / `HYROX トレーニング 施設 関東`
- 英語: `best indoor pickleball Tokyo area` / `pickleball Chiba`

<市> は施設所在地と近隣市、<県> は千葉・東京。施設情報の正本は `docs/reviews/listing-2026-09-28/facility-profile.md`。

### 2. 上位を調べる

WebSearch で各検索語の上位10件を取り、まとめ記事・ランキング・施設一覧(単独施設の公式ページ以外)を WebFetch で開いて記録する:

- タイトル / URL / 運営者
- どの検索語で何位か
- **THE PICKLE BANG THEORY(ピクルバン / PBT)が載っているか**(載っていれば記述を短く引用)
- 近隣の競合が載っているか
- 更新日(見えれば)
- 掲載依頼の窓口(サイトが**掲載依頼・問い合わせ用に公開している**フォーム・メールのみ)

あわせて自サイトのページが各検索語で何位かを記録する。取得できなかった検索・ページは「未確認」と書く。推測で埋めない。

WebSearch は Google 日本版ではない(地域指定なし)ので、順位は目安として扱い、台帳の先頭にその旨を書く。自サイトの順位は Search Console の検索語別データで裏取りする。

### 3. 台帳に書く

記録先: `docs/reviews/listing-2026-09-28/geo-listicles.md`(無ければ作る)。先頭に調査日と検索語を書き、表は1行1記事。前回からの変化(新たに載った・消えた・順位が動いた)を冒頭に3行以内でまとめる。

### 4. 依頼先の優先順位を付ける

優先度が高いのは **未掲載 × 複数の検索語で上位 × 窓口あり**。`facility-profile.md` の既存候補(Pickleheads・pickleballnavi.jp・pickle-times など)と重なるものはその旨を書き、二重に依頼しない。

### 5. 依頼文の下書き

優先上位の記事ごとに、短く個別の依頼文を下書きする。載せる事実は `facility-profile.md` と CLAUDE.md の確定事実(営業時間 6:00-23:00・コート3面・デコターフ)だけ。料金など未確定・変わりやすい情報は書かず、公式サイトへの案内にする。送信はオーナーが内容を確認して行う。

### 6. 自サイト側の提案(任意)

まとめ記事の構成から「AI が引用しやすい情報」(アクセス・料金の案内先・予約方法・対応レベルなど)が自サイトの該当ページに欠けていれば、改稿案として挙げる。本文の書き直しは CLAUDE.md の「記事の対話運用」に従う(消えた要素チェックを含む)。
