# NG→OK 対比例(やってはいけない型と直し方)

> ここは**1論点1ペアの短い断片**で「ありがちな事故と直し方」を示す、人が依頼した任意アドバイス・本文コメント修正用の参考資料。下書き生成プロンプトには渡さない。正典は style-guide §13/§14/§15/§7。
> **執筆担当には渡さない**(執筆カードに含めない)。禁止例を執筆時に並べると、モデルが不自然な言い換えに逃げて逆効果になる。

## AI病理カテゴリ

各例は、LLM が書くと出やすい「病理」ごとに分類してある。左が症状(NG)、右が直し方(OK)。

<example index="1" topic="タイトルの無意味な羅列 (§15)">
<ng>
市川・本八幡・千葉で人気沸騰！初心者も安心の屋内ピックルボール完全ガイド｜総武線・都営新宿線スポーツ施設
</ng>
<ok>
ピックルボール、市川市でどこでできる？場所の選び方ガイド【体育館・クラブ・屋内専用施設】
</ok>
<why>
NG がダメなのは「人気沸騰!」という根拠のない煽り(§6)と、同種の地名・路線名を3つ以上並べる羅列。疑問形・【】での範囲提示・「ガイド」は§15のとおり**使ってよい**。OK は読者の検索意図(どこでできる?)が一目で伝わり、記事の中身(3タイプ比較)も予告している。
</why>
</example>

<example index="2" topic="中身のない導入 (§14/§4-1)">
<ng>
ピックルボールは、テニス・卓球・バドミントンの要素を組み合わせた、近年急速に人気を集めているスポーツです。健康にも良く、幅広い世代に愛されています。その魅力は計り知れません。
</ng>
<ok>
市川市内でピックルボールができる場所はどこ？——そんな疑問を持って検索している方は少なくありません。この記事では、市内でプレーできる場所を3タイプに整理して、自分に合う選び方まで案内します。
</ok>
<why>
NG は競技の一般説明とぼかし語(「魅力は計り知れません」)だけで、読者の疑問に向き合っていない。OK は読者の疑問をそのまま受け止め、この記事で何が分かるかを先に示す(§4-1 のリードの型。軽いメタ言及は読者への親切として OK)。
</why>
</example>

<example index="3" topic="未確定情報の断定 (§13)">
<ng>
1時間2,000円で、本八幡駅から徒歩3分。予約なしでも必ず入れます。
</ng>
<ok>
営業時間は6:00-23:00、本八幡駅から徒歩1分の屋内コートです。仕事帰りにも寄れます。料金は変わることがあるので、最新情報をご確認ください。
</ok>
<why>
料金・正確な所要分(徒歩◯分の創作)・未確定の断定は facility-context の doNotWrite(列挙はファイルが正典)。一方、営業時間 6:00-23:00・コート3面・デコターフ・徒歩1分は公表済みの確定事実(#217)なので断定してよい——むしろ一次情報として積極的に書く(§15)。可変情報だけを「最新情報をご確認ください」に逃がす。
</why>
</example>

<example index="4" topic="競合記事の焼き直し(独自視点なし)">
<ng>
ピックルボールの基本ルールは、サーブはアンダーハンドで、ノーボレーゾーン(キッチン)があり、11点先取で…(一般的なルール説明が続く)
</ng>
<ok>
ルールはネットで5分調べれば分かる。むしろ最初の壁は「一緒に打つ人がいない」こと。本八幡の屋内コートで、一人で来た人がどう輪に入るかを書く。
</ok>
<why>
どこにでもあるルール要約は検索で勝てず、Google の Helpful Content でも量産・順位狙いの焼き直しは警告サイン。施設だから言える一次情報(一人参加・屋内・地域)で角度を変える。一般論しか出せないなら保留して報告。
</why>
</example>

<example index="5" topic="CTA が強すぎる (§7)">
<ng>
今すぐ予約しないと損！満員必至の体験会はこちら → 【今すぐ申し込む】 お見逃しなく！！
</ng>
<ok>
気になったら、まずは雰囲気だけでも。最新の開催情報は公式 Instagram で見られます。
</ok>
<why>
煽り・誇大・感嘆符の連打はプレミアム施設のブランドに反する(§7・§12 抑える味)。CTA は1つ、静かに。未確定の体験会日時は断定しない(§13)。
</why>
</example>

<example index="A" topic="言い回しの発明(非慣用コロケーション) (§14 原則2)">
<ng>
空模様に予定を握られています。それでも、この地味を積んでいます。
</ng>
<ok>
天気に予定を左右されます。それでも、この地味な積み重ねを続けています。
</ok>
<why>
LLM は局所的に確率の高い語を繋いで、慣用にない表現を発明する(「予定を握る」「地味を積む」は日本語のコロケーションとして成立しない)。人にしか使わない動詞を物事に当てたり、形容動詞を名詞のように積んだりするのがこの病理。自信がなければ平易な言い方に倒す——凡庸で正しい > 独創的で不自然。人が任意アドバイスを依頼した場合は「声に出して詰まる」「人にしか使えない語を物に使った」箇所として確認する。
</why>
</example>

<example index="B" topic="修辞の過剰適用(決め台詞の畳みかけ) (§11-3/§14)">
<ng>
天気に、予定を握られない。屋内、それが答え。3面のコート。待ち時間はゼロ。膝の軽さ、それがデコターフ。近いから、続く。理屈はいらない。ただ、打つだけ。
</ng>
<ok>
屋内なら、天気に予定を左右されません。3面あるので待ち時間もほとんど出ません。床はデコターフで、膝や足首への負担が屋外より軽い。近いから、続く。理屈より、まず一度打ってみてください。
</ok>
<why>
決め台詞・体言止めの回数制限(旧・修辞予算)は廃止したが、NG のように**全段落で畳みかける**と読者が疲れ、AI っぽさの典型になる。OK は同じ内容を素直なですます調で書き、装飾を効かせ所に絞った。styleLintや人の確認で気づいた場合も、本文は自動変更せず必要に応じて修正を依頼する。
</why>
</example>
