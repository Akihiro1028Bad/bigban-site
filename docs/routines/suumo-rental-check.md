# 賃貸新着チェック(SUUMO)— ローカル実行ルーティン

> **実行環境**: ローカルの Claude セッション + Claude in Chrome 拡張。
> クラウドルーティンでは実行不可(ブラウザ拡張が使えず、リモート環境から suumo.jp への通信がネットワークポリシーで遮断されるため)。
> ローカルのスケジュールタスクとして登録するか、毎朝手動でこのプロンプトを貼り付けて実行する。
>
> **実行スケジュール(確定)**: 毎朝 **8:00** の1回。
> 新着は不動産会社の営業時間中(9〜19時ごろ)に投入されるため、朝8時に前日分をまとめて拾い、
> 仲介店が開く10時に問い合わせできるようにする。
> 繁忙期(1〜3月)や引っ越し直前のみ **夜21:00** を追加(当日分を夜のうちにメール問い合わせし、翌朝の対応キュー先頭に入るため)。
> 水曜は不動産業界の定休が多く新着はほぼ出ない(夜回を省いてよい)。
> ※1日2回まで。SUUMO への負荷とブロック回避のため、これ以上頻度を上げない。

以下がプロンプト本文。

---

あなたの仕事は賃貸物件の新着チェックです。Claude in Chrome拡張でブラウザに接続して実行してください。

■ 状態ファイル
`~/suumo-check/seen.json` に既読物件を保存している(形式: `{"seen": [{"id": "<建物詳細URLまたは物件ID>", "name": "...", "firstSeen": "YYYY-MM-DD"}], "watch": [{"name": "ソレイユメゾン本八幡", "url": "..."}, {"name": "シエスタ", "url": "..."}, {"name": "カノン本八幡", "url": "..."}]}`)
- 実行開始時に読み込む。ファイルがなければ初回実行として、今回の全ヒットを seen に記録して「初回登録のみ・報告対象なし」と報告して終了。
- 実行終了時に新着分を追記して保存する。

■ 取得対象(SUUMO検索結果、全ページ巡回)
https://suumo.jp/jj/chintai/ichiran/FR301FC005/ に以下のクエリを付けた4種:

1. `?ar=030&bs=040&ta=12&sc=12203&cb=0.0&ct=12.0&md=04&et=10&mb=0&mt=9999999&cn=15&pc=50`(市川市・1LDK・12万以下・築15年以内)
2. `?ar=030&bs=040&ta=13&sc=13123&cb=0.0&ct=12.0&md=04&et=10&mb=0&mt=9999999&cn=15&pc=50`(江戸川区・1LDK・同条件)
3. `?ar=030&bs=040&ta=12&sc=12203&cb=0.0&ct=12.0&md=01&md=02&md=03&et=10&cn=5&mb=20&mt=9999999&pc=50`(市川市・1R/1K/1DK・12万以下・築5年以内・20㎡以上)
4. `?ar=030&bs=040&ta=13&sc=13123&cb=0.0&ct=12.0&md=01&md=02&md=03&et=10&cn=5&mb=20&mt=9999999&pc=50`(江戸川区・1R/1K/1DK・同条件)

- 2ページ目以降は `&pn=2` のように付与(1ページ50件)。ページ先頭のヒット件数から総ページ数を計算して巡回し、物件0件のページに達したら打ち切る。
- ページ間は2〜3秒待機。取得に失敗したクエリは「取得失敗」として必ず報告し、「新着なし」とは扱わない。

■ 絞り込み条件
- JR総武線または都営新宿線の「市川・本八幡・篠崎・一之江・瑞江・船堀・小岩・新小岩・平井」のいずれかの駅から徒歩10分以内。「バス○分」表記の駅は判定に使わない。
- 礼金1ヶ月以下(礼金なしを含む)
- 賃料+管理費の合計が12万円を超えるものは報告時に除外
- seen.json に記録済みの物件は除外。同一建物で複数部屋がヒットした場合は建物単位に集約し、最安の部屋を代表に部屋数を併記。

■ 新着があった場合
各物件の詳細ページを1件ずつ開いて確認し、閉じてから次へ:
- 設備欄に「追焚」の記載があるか
- 「ほか初期費用」欄の金額と内訳
- 契約期間が定期借家でないか(定期借家なら明記)

■ 報告フォーマット
1. 新着物件(建物単位):
   物件名|駅・徒歩分|賃料+管理費|広さ|築年|敷/礼|追い焚き有無|隠れ初期費用|定期借家か|詳細URL
   ※追い焚きあり・30㎡以上には【おすすめ】を付ける
2. 既知候補の生存確認: watch の3件は保存済みURLを直接開き、「掲載終了」表示なら【要注意】として先頭で報告
3. 新着ゼロかつ候補3件生存なら「新着なし・候補3件生存」と一行で報告
4. 末尾に必ず: 各クエリのヒット件数・巡回ページ数・取得成否

---

## 初回セットアップ(要対応)

- `~/suumo-check/seen.json` の `watch` 3件(ソレイユメゾン本八幡/シエスタ/カノン本八幡)の詳細ページURLを控えて埋める。初回実行時に Claude に検索結果から探させて記録させてもよい。
- 初回実行は「seen への登録のみ」で終わる(その時点の掲載を既読化するため)。2回目以降から差分=新着として報告される。
