# 施設の事実を正本にそろえる(szb-506) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** サイト・特商法・構造化データの施設情報を、オーナー確認済みの正本(年中無休・事前Web決済・電話は特商法のみ・キャンセルは LaBOLA 規定)に一致させる。

**Architecture:** 変更は `messages/ja.json`・`messages/en.json` の該当行、構造化データ生成関数からの `telephone` 削除、手順書1本のみ。新規コンポーネント・依存は無し。各タスクは「既存テストの期待値を先に更新(Red)→ 文言/コード変更(Green)」。

**Tech Stack:** Next.js 16 / next-intl / Vitest + React Testing Library / TypeScript strict

設計書: `docs/superpowers/specs/2026-10-01-szb-506-facts-design.md`

## Global Constraints

- コミットは司令塔の OK が出るまで一切しない(各タスクの Commit ステップは「OK後にまとめて」)。コミットメッセージは日本語の Conventional Commits、末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`
- `messages/ja.json`・`messages/en.json` は**該当行だけ**を Edit で変更し、他の行は整形しない(他セッションと衝突する)
- カバレッジ100%維持。`vitest.config.ts` の除外追加・`istanbul ignore` 追加・`.only/.skip` は禁止
- `any` 禁止、`import type` を使う
- ネガティブ情報(天井が低い等)は書かない。駐車場は「近隣のコインパーキングをご利用ください」の案内形式を維持
- 未確定情報(料金・日時・所要時間・「24時間」)を断定しない。ティザー keywords の「24時間」は触らない
- 特商法の電話番号表示・`tel:` リンクは法定表示なので残す
- ディスク空きが少ない。`npm ci` はオーナーの空き確保後(司令塔から指示あり)。それまではテスト実行不可。本体の node_modules への symlink は禁止
- テスト実行コマンド: 単体 `npx vitest run <path>`、全体 `npm run test:coverage`
