# szb-509 LaBOLA への渡し方を改善する — 設計書

- 起票: 2026-10-01 / issue: #509 / ブランチ: `feature/szb-509-labola-handoff`
- 目的: LaBOLA で枠を選ぶ段(週カレンダー閲覧→予約情報 約23%、予約情報→顧客情報 約57%)の離脱を減らす。
- 効果判定: 「サイトのカード押下→予約情報」(現状約20%)。#505 の計測修理の後に測る。

## 確定した方針(オーナー回答 2026-10-01)

- 「今日 / 明日 / 今週末」の日付ボタンを置き、押すとその日の LaBOLA **1日表示**(タブ指定つき)へ直行する。
- メインの予約ボタンも「今日の1日表示」へ。
- 日付は JST で、クライアント側で計算する。
- イベント詳細・スクール(体験会)の直リンクは作らない(#510 は保留中)。

## LaBOLA の URL 仕様(公開ページの閲覧で確認、2026-10-01)

| 用途 | URL |
|---|---|
| 1日表示 | `https://yoyaku.labola.jp/r/shop/3473/calendar/2026/10/5/?tab_name=<タブ名>`(月日はゼロ埋めなし) |
| 週表示(日付つき) | `.../calendar_week/2026/10/5/?tab_name=<タブ名>` |
| 枠ごとの予約開始 | `https://yoyaku.labola.jp/r/booking/rental/shop/3473/facility/<コートID>/<YYYYMMDD>-<HHMM>-<HHMM>/customer-type/`(空き状況がサイトから見えないため使わない) |
| ログイン/ビジター選択 | 上記 `customer-type` 画面。「ビジターで予約」は「ログイン」「LaBOLAアカウントでログイン」の**下**にある |

## 変更内容

### 1. 日付ボタンと1日表示(コード)

- `src/constants/site.ts`: `labolaDayUrl(tabName, ymd)` を追加(既存の `labolaCurrentWeekUrl` の隣)。既存の週表示 URL 定数は残し、JS 無効・SSR 時のフォールバックにする。
- `src/lib/labola/quickDates.ts`(純関数): `toJstYmd(now)`、`buildQuickDates(now)`。今日・明日・直近の土・直近の日を重複なく日付順に返す。今日/明日が土日と重なるときは「今日/明日」のラベルを優先する。
- `src/components/reserve/ReserveChoice.tsx`: 枠貸しの2枚(コート、HYROX エリア)に日付ボタン行を追加。マウント後に「今日」を計算し、メインボタンの href を今日の1日表示へ差し替える(マウント前は従来の週表示 URL)。レッスン/クラス・イベントのカードは変えない。
- 日付ボタンは `<a href target=_blank>` のまま。JS ナビゲーションにしない(GA4 のクロスドメインリンカーは `<a>` のクリック時に `_gl` を付けるため)。

### 2. 計測(既存を壊さない)

- メインボタン: `trackCtaClick("reservation", location, label)` と `trackLabolaEntry(kind)` を現状のまま送る(location・label・イベント名は不変)。
- 日付ボタン: 同じ2イベントを送る。ただし `location` は `<カードの location>_date_<today|tomorrow|saturday|sunday>`、label は CTA の文言。分母(カード押下)が日付ボタン経由でも欠けず、切り口で分けられる。
- 追加依存なし。

### 3. 「会員登録なしで予約できます」の明記(コード+文言)

- LaBOLA へ進む3枚(コート、HYROX エリア、レッスン/クラス)のボタン直下に注記: 「会員登録なしで予約できます。ログイン画面を下へスクロールして『ビジターで予約』を選んでください。」
- `src/components/reserve/ReserveVisitorGuide.tsx`(新規)を `page.tsx` の ReserveHero と ReserveChoice の間に1セクション追加:
  - LaBOLA での流れ(日付と空き枠を選ぶ → ログイン画面の下の「ビジターで予約」→ 予約者情報 → 決済)。段数・所要分は書かない(未確定)。
  - 会員登録(無料)する人向けの注意(登録の手前): メールが届かないときは迷惑メールフォルダ・受信拒否設定・入力したアドレスを確認、それでも届かなければビジター予約で先に進める。

### 4. 会員登録メール未着の対処(登録の後)

- `Reserve.faq.items` の末尾に「会員登録のメールが届きません」を追加(迷惑メール・アドレス確認・ビジター予約で先に進める・それでも届かなければ問い合わせフォーム `/about#contact` または Instagram DM)。FAQ の構造化データにも載る。
- 書かないこと: LaBOLA の送信元アドレス、再送の操作、PBT Club の登録料。一般会員の登録は無料(オーナー確認済み・2026-10-01)なので「会員登録（無料）」と書いてよい。

### 5. LaBOLA 側の確認事項(手順書のみ・オーナーが実施)

- `docs/operations/labola-handoff-requests.md` に、問い合わせ文面つきでまとめる: ビジター予約をログイン画面の上に出せるか、会員登録メールの送信元と再送方法、登録案内文への追記可否。
