# szb-428「はじめての方へ」ページ新設 + ナビ常設 — 設計書

## 1. 目的

予約直前の初めての人・全員初心者のグループが、予約前に迷う点(流れ・持ち物・料金の人数あたり・受付開始日・キャンセル・入館・施設の正直な仕様)を **1 ページで解消**し、コート予約へ進めるようにする。予約の備考欄に出ている疑問(全員初心者でよいか・道具の貸出・人数変更・早朝の入り方)を予約前に答える。

## 3. ページ構成(上から)

デザインはオーナーの好み(演出控えめ・エディトリアル・ダーク)。既存の `ReserveHero`/`ReserveInfo`/`ReserveFaq` と同じトーン(`bg-deep-black`、`text-accent` の小見出し、`max-w-7xl`、`revealInitial`+`whileInView once`)。`prefers-reduced-motion` 対応は既存ヘルパーに従う。

1. **Hero**: `FIRST VISIT` / はじめての方へ。リードは結論先出し 1〜2 文(「ピックルボールが初めてでも、全員初心者のグループでも楽しめます。持ち物はノーマーキングシューズだけ。」)。直下に「ルールは事前にこちらで確認できます」の一文と導線(`BEGINNER_GUIDE_PATH`)。直下に主 CTA「コートを予約する」(`RESERVE_PATH`)。
2. **ご利用の流れ**(縦 4 ステップ、番号つき): 予約 → LaBOLA で事前 Web 決済 → 入館(無人対応・予約時間になったらそのまま)→ プレー。
3. **持ち物とレンタル**: ノーマーキングシューズ(貸出なし)/ パドル 1 本 ¥500(1 コート 6 本まで)。ボールの貸出は**記載なし**(未確定のため書かない)。
4. **料金と人数の目安**: `CourtPriceTable` を再利用 + 「ダブルスなら 4 人で割ると 1 人あたり」の例を時間帯別に併記(1 時間・税込・レンタル別)。1 面 4 人は前提の例であって人数上限ではない旨を一文で。PBT CLUB への入口(→ `/pbt-club`)。
5. **予約のルール**: 受付は一般 14 日前から・PBT CLUB 会員は 30 日前から。キャンセル・変更は LaBOLA の規定(予約時に確認)。開始に遅れても枠の時間内。
6. **施設について**: 全天候型インドア・空調完備・コート 3 面(デコターフ)・年中無休 6:00–23:00。男女別更衣室・ラウンジ・自販機。シャワーなし。お車の方は近隣のコインパーキングをご利用ください(専用駐車場の有無は書かない)。**天井・照明の節は設けない。**
7. **次の一歩への入口**: コート予約(`/reserve`)/ HYROX 体験会(`/hyrox`)/ PBT CLUB(`/pbt-club`)。#510 の体験会表示は将来、独立コンポーネントとしてここに差し込める余白(セクション)を残す(今回は何も出さない)。
8. **FAQ**(`<details>`、FAQPage 構造化データ): 全員初心者でも? 1 人でも? 持ち物は? 人数が変わったら? 支払いは? キャンセルは?

## 4. ナビ常設

- `NAV_ITEMS` に `{ id: "firstVisit", kind: "page", href: "/first-visit" }` を**先頭**に追加(初めての人に最初に目に入る位置。ヘッダー・モバイルメニュー・フッターの 3 か所が自動で追従)。
- ラベル: 英 `FIRST VISIT` / 日 `はじめての方へ`。`Navigation.firstVisit` / `firstVisitJa`(ja/en とも)。
- `SECTION_IDS` は anchor のみ抽出なので影響なし。`HomeNavigation.test.tsx` の項目数アサーションを更新。
- **リスク**: デスクトップ(xl)で項目が 9→10 になり、ロゴ・言語切替・予約ボタンとの横幅が詰まる。1280/1440px で実測し、溢れる場合は xl 帯の `gap-8` を縮める(ナビの CSS だけ・他ファイルは触らない)。
- ホーム内の入口: `HomeUsageFlow`(ご利用の流れ)の末尾に「はじめての方へ詳しく」リンクを 1 本。ヒーローへの 3 択追加は範囲外(司令塔判断で別 issue)。
