# docs/growth — グロースコパイロットの運用資産

分析・施策提案・記事企画を「クラウドルーチン(準備)＋対話(判断・実行)」の二層で回すための置き場。

| ファイル | 内容 |
|---|---|
| `analysis-contract.md` | 全ルーチン共通の取得範囲・指標・期間・判定の正典 |
| `playbook.md` | 施策判定の「学び」を1行ずつ積む台帳。**全ルーチンのプロンプトが読む**ため、負けた打ち手は再提案されない |
| `seasonal.md` | 季節・イベントの年間表。週次ドライバーの3週先読みが提案タイミングを決めるのに使う |
| `routines/daily-watch.md` | 日次ウォッチ(毎朝 09:00・台帳取り込み後)のルーチンプロンプト正本。**異常時のみ通知(沈黙が正常)** |
| `routines/morning-brief.md` | モーニングブリーフ(毎朝 08:00)のルーチンプロンプト正本。グロース専用リサーチ。**Mac起動時に実行。未起動日は実行されない**。末尾の「## 施策の種」テーブルを週次R1が収穫する |
| `routines/weekly-driver.md` | 週次ドライバー(木曜 10:00)のルーチンプロンプト正本。月次ストラテジストは第1木曜に拡張して実行 |
| `setup-cloud-routines.md` | オーナー向けセットアップ手順(env secrets 5つ・停止/再開/削除・トラブル確認順) |
| (ローカル) `~/.claude/scheduled-tasks/labola-snapshot/` | **ローカル橋渡しタスク**(毎朝07:30・Mac起動時)。クラウドから読めない Labola カレンダーを取得し Notion「Labola空き枠スナップショット」を上書き更新。週次が72時間以内なら実測として使う |
