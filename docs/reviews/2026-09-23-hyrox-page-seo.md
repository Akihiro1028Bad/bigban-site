## 6. 改善施策(優先順)

### A. ページの中身(コード変更・PR)

1. **title・description を「千葉のHYROX公式ジムを探す人」向けに書き換える**
   - title 案: `HYROX（ハイロックス）公式トレーニングジム｜千葉・本八幡駅徒歩1分 | THE PICKLE BANG THEORY`
   - description 案: `HYROX公式トレーニングクラブ認定。千葉・本八幡駅徒歩1分(JR総武線・都営新宿線)。公式8種目の器具を常設し、現HYROX日本代表・関吉大亮コーチが指導。初めての方は体験会(50分・3,000円)から。6:00〜23:00営業。`
2. **見出しを日本語の検索語に**: h1 は見た目の「HYROX」を保ったまま「本八幡のHYROX公式トレーニングジム」を含める。h2 は「設備・器具」「料金・体験会」「アクセス」などの日本語を正にし、英語は飾りにする。
3. **不足しているセクションを足す**
   - 公式認定(HYROX TRAINING CLUB の名称・認定・公式ジム検索へのリンク)= issue #421
   - アクセス(本八幡駅徒歩1分、JR総武線・都営新宿線、都内・船橋方面からの行き方。所要分数は要確認)
   - 体験会・グループの料金(体験会・モーニングクラス 各 3,000円、HYROX TRAINING @ DAISUKE CLASS 4,500円。LaBOLA と一致させる)
   - よくある質問 5〜7 問(HYROXジムとは/費用/初心者でも参加できるか/持ち物/予約方法/オレンジセオリー等の他ジムとの違いは書かない)+ FAQPage 構造化データ
4. **構造化データを埋める**: HYROX 用 ExerciseGym に address・geo・openingHoursSpecification・telephone・image・priceRange を入れ、関吉コーチを Person(employee)で結ぶ。座標は現地で正しい方に揃える。
5. **表示速度**: h1 と見出し語を「透明から出す」アニメーションをやめるか CSS に替え、最初から見える状態で描画する。LCP 3.1 秒 → 2.5 秒未満が目標。
6. **内部リンク**: 記事から /hyrox へのアンカーを「本八幡のHYROX公式トレーニングジム」などに揃える。/hyrox から体験会ニュース・参加費ガイド・認定ニュースへリンクを出す。
