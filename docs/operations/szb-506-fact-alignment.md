# 施設の事実の突き合わせ手順書(szb-506)

- 目的: サイト・LaBOLA・Google ビジネスプロフィール(GBP)・特商法・構造化データで食い違っていた施設の事実を、1つの正本にそろえる
- 範囲: **LaBOLA と GBP の管理画面での修正はオーナーが行う**。サイト側(文言・構造化データ)は PR で修正済み
- 出典: オーナー確認(2026-10-01)、issue #506

## 1. 正本

| 項目 | 正本 |
|---|---|
| 定休日 | 年中無休 |
| 営業時間 | 毎日 6:00-25:00(翌1:00)。公表済みの確定事実 |
| 駐車場 | 専用なし。近隣のコインパーキングをご利用いただく |
| シャワー | なし |
| パドル貸出 | 1コートにつき6本まで(1本 ¥500) |
| 電話番号 | 特商法ページの法定表示のみ。それ以外には載せない。問い合わせはフォーム・LINE |
| キャンセル規定 | LaBOLA の規定が正。サイトは「規定に従う」と案内する |
| 支払い | LaBOLA での事前 Web 決済(クレジットカード・PayPay)。現地払いの案内はしない |
| 所在階 | 6F(八幡ハタビル 6階) |

## 2. サイト側で直したもの(PR 済み・確認のみ)

- 営業時間の「不定休」を「年中無休」に(予約ページ・トップのアクセス・英語版)
- FAQ「支払い方法」を事前オンライン決済の案内に(「現地で」を削除。日英)
- 特商法の「返品・交換・キャンセル」に、予約のキャンセル・変更は予約システム(LaBOLA)の規定に従う旨を追記(日英。既存の行は残す)
- 構造化データ(SportsActivityLocation・ExerciseGym)から `telephone` を削除
- 予約ページの利用案内に「シャワー設備はございません。」を追加

## 3. LaBOLA 管理画面での修正(オーナー)

画面名は LaBOLA の管理画面で実際の表記を確認し、見つからない場合は設備欄・予約フォーム設定のあたりを探す。

1. **店舗ページの設備欄**
   - 「駐車場」を外す
   - 「シャワー室(男女)」を外す
   - 確認: 公開側の店舗ページを開き、設備欄に両方が出ていない
2. **予約フォームのパドル貸出**
   - 上限を 8 本 → **6 本**に直す(1コートにつき6本まで)
   - 確認: 公開側の予約フォームで7本以上を選べない
3. **店舗ページの文面**
   - 「将来24時間営業予定」の記述を削除する(未確定情報。ポータルサイトがこの文面を転載している)
   - 確認: 削除後、転載先のポータルに反映されたかを数日後に確認
4. **キャンセル規定の現行内容を確認**
   - サイトの特商法・利用案内は「LaBOLA の規定に従う」形なので、サイト側の文面を規定に合わせて書き換える必要はない
   - LaBOLA 側で規定を変えたときは、予約画面に表示される内容が最新であることだけ確認する

## 4. GBP での修正(オーナー)

1. ビジネスプロフィールの管理画面 > 情報 > 住所で、所在階を「1階」から **6F** に直す
   - 確認: 検索結果・マップの表示が「6F」「6階」になっている(反映に時間がかかる場合あり)
2. 営業時間が「毎日 6:00-25:00(翌1:00)」と一致しているか確認する(今回の対象外だが、突き合わせのついでに見る)
