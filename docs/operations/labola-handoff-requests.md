# LaBOLA への確認事項(予約の渡し方 / szb-509)

- 起票: 2026-10-01 / issue: #509 / 実施: オーナー(LaBOLA の管理画面またはサポート窓口)
- 背景: LaBOLA で枠を選ぶ段(週カレンダー閲覧→予約情報 約23%、予約情報→顧客情報 約57%)の離脱が大きい。サイト側では「今日の1日表示」「日付ボタン」「ビジター予約の明記」で渡し方を直したが、LaBOLA 側の画面でしか直せない点がある。

## 確認する3点

| # | 確認内容 | 分かったときの使い道 |
|---|---|---|
| 1 | 予約の途中で最初に出る「ログイン画面」で、**「ビジターで予約」をログインフォームより上に出せるか**(表示順の設定・テンプレートの切り替えなど) | モバイルではビジター予約が下へスクロールしないと見えない。上に出せればサイト側の注記を「ログイン画面の上の」に直す |
| 2 | **会員登録の確認メールの送信元アドレス**と、**届かないときの再送方法**(ユーザー側の操作か、管理者側の操作か) | サイトの FAQ「会員登録のメールが届きません」に、送信元の受信許可と再送手順を足す(現状は一般的な確認事項のみ) |
| 3 | 会員登録の画面・予約画面の**案内文(お知らせ欄・店舗の紹介文)に文章を追記できるか** | 「会員登録なしで予約できます(ログイン画面の下の『ビジターで予約』)」を LaBOLA 側にも置く |

## 問い合わせ文面(コピーして使う)

> THE PICKLE BANG THEORY(店舗ID 3473)です。予約画面について3点教えてください。
> 1. 予約の途中で表示されるログイン画面で、「ビジターで予約」をログインフォームより上(スクロール不要の位置)に表示する設定はありますか。
> 2. 会員登録の確認メールの送信元アドレスと、メールが届かないお客様への再送方法を教えてください。
