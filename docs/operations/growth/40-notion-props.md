# Notion「記事ネタ案」DB 必要プロパティ一覧

> 各ループは pull 型で Notion にプロパティを読み書きする。**事前追加が前提**だが、コードは**欠落耐性**(未追加でも沈黙落ちせず動く/報告する)。
> data source 例: `5adab8b1-f182-4123-b963-9463a2580d4a`。詳細仕様は各ループの節([30-loops.md](30-loops.md) 等)。

## ステータス・基本

| プロパティ | 型 | 用途 |
|---|---|---|
| `ステータス` | select | `承認`/`生成中`(#108)/`下書き作成済み`/`却下`/`公開済み`。**「生成中」値の事前追加が前提**。 |
| `タイトル案` | title | 下書きタイトルにそのまま使う(#176)。修正ループ(#139B)で上書き可。 |

## 仮説プロパティ(週次 #計測強化 S5・下書きブリーフで再利用)

`狙う読者` / `検索意図` / `想定CTA` / `成功指標` / `記事タイプ` / `勝ち筋`

## 修正ループ(#40 / #139B)

`修正指示` / `修正ステータス` / `修正案` / `修正依頼時刻`(6プロパティ)
＋ #139B: `修正タイトル指示` / `修正タイトル案`(後者2つが無くても構成案修正は動く)

## 下書きプレビュー＋手動編集(#72)

`下書きID` / `下書きプレビューキー`(＋ Vercel 環境変数 `MICROCMS_CONTENT_API_KEY`)

## アイキャッチ AI 再生成(#144)

`アイキャッチ再生成指示` / `アイキャッチ再生成ステータス` / `アイキャッチ再生成依頼時刻`
＋ ミラー: `アイキャッチURL`

## 本文画像 AI 再生成(#156)

`本文画像再生成指示` / `本文画像再生成ステータス` / `本文画像再生成依頼時刻` / `本文画像再生成対象`(対象src)
＋ ミラー: `下書き本文HTML`(#95)

## スタイリング・アドバイザー(#146)

`アドバイス指示` / `アドバイスステータス` / `アドバイス結果` / `アドバイス依頼時刻`

## 装飾アシスタント(#147)

`装飾指示` / `装飾ステータス` / `装飾提案` / `装飾依頼時刻`

## 計測ループ(#C4)

`成績データ`(テキスト) / `成績更新時刻`(日付)

## 公開キュー予約(#H24)

`公開予約時刻`(日付)
